# 0002. プロダクトスコープ：自分専用・読み取り専用・AI なし

- Status: Accepted
- Date: 2026-10-05

## Context

目的は TypeScript コードのレビューで「読む効率」を上げることです。スコープを絞らないと、配布、編集、GitHub への書き戻し、AI といった周辺機能に工数を取られてしまいます。

## Decision

- **利用者は開発者本人のみ**。コード署名、notarize、自動更新は行わない。arm64 のみに対応する
- **読み取り専用**。アプリ内で編集はしない。「VS Code で開く」ボタンで外部エディタに渡す
- **GitHub への書き戻しはしない**。PR は読むだけで、コメントやレビューの送信は将来フェーズとする
- **AI 機能は入れない**。LLM による要約などは将来の拡張点としてのみ扱う
- 対象言語は `.ts` / `.tsx` / `.mts` / `.cts`。`.vue` / `.svelte` などは対象外。monorepo と tsconfig の project references は最初から対象に含める

## Consequences

- ファイル監視や解析キャッシュの整合性が単純になる（自分でファイルを書き換えないため）
- 未署名なので、`safeStorage` などの一部 API の挙動を Phase 0 / 1 で確認する必要がある（[0013](./0013-github-auth-per-project-pat.md)）

## Revisit when

- チームで配布したくなったとき（署名と自動更新の ADR を新しく起こす）
- PR へのコメント投稿が必要になったとき
