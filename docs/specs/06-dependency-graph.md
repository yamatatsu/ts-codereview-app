# 06. 依存グラフとレビュー順

## データ

- ImportGraph（head）：Workspace 全体
- ImportGraph（base）：変更ファイルとその 1 ホップ先（[ADR 0011](../adr/0011-import-graph-with-oxc.md)）
- エッジの属性：`kind: 'static' | 'dynamic' | 'type-only' | 're-export'`、`change: 'added' | 'removed' | 'unchanged'`

## 依存ビュー

- 表示範囲（デフォルト）：変更ファイル同士と、そこから 1 ホップ先（依存先と被依存の両方向）
  - ホップ数は 0〜3 で切り替えられる
- 表示形式：グラフ（React Flow と elkjs のレイヤードレイアウト）とリストを切り替えられる
- ノードの見た目
  - 変更ファイル：status の色（A / M / D / R）
  - 変更されていないファイル：グレー
  - テストファイル：アイコンで区別する
  - Viewed 済み：チェックを付ける
  - 外部パッケージ：1 ノードに集約する
- エッジの見た目：`added` は緑、`removed` は赤の破線、`type-only` は細線
- フィルター：テストの表示・非表示、type-only の表示・非表示、外部パッケージの表示・非表示
- ノードをクリックするとそのファイルを開き、ダブルクリックでそのノードを中心に再展開する
- Context panel：選択中のファイルについて、Imports（依存先）と Imported by（被依存）をリストで表示する。変更ファイルを強調する

## ReviewOrder（「次」に読むもの）

- 変更ファイル（`impl`）の、head グラフ上での誘導部分グラフに対してトポロジカルソートを行う
  - **依存される側（葉）から先に**並べる
- 循環は強連結成分（SCC）にまとめ、成分の中はパスの辞書順に並べる
- テストファイルは、対応する実装の直後に挿入する（TestLink が primary のもの）
- ファイル一覧の既定の並びは「レビュー順」とし、「パス順」に切り替えられる
- 「次の未 Viewed ファイル」（`Cmd+Alt+→`）は、このレビュー順に従う

## 受け入れ条件

- `a.ts → b.ts → c.ts`（a が b を import）の変更では、レビュー順が `c, b, a` になる
- 循環 `a ↔ b` は 1 グループとして表示される
- 2,000 ファイルの Workspace で、head グラフの初回構築が 5 秒以内に終わる（M 系 Mac で計測）
