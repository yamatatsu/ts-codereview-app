# 03. diff 表示

## 表示

- @pierre/diffs で表示する。split と unified を切り替えられ、設定はグローバルに保存する
- 入力は base と head の blob の全文。行 diff は @pierre/diffs が計算する
- 大きなファイルは仮想化して描画する。5,000 行を超える diff は折りたたんだ状態で始め、明示的に展開する
- `collapsed` に分類されたファイルは、一覧の最下部にまとめ、中身は既定で非表示にする
- シンタックスハイライトのテーマは、ライトとダークで Shiki のテーマを切り替える

## 変更されていないファイルの表示（ジャンプ先）

- 同じビューア領域に「Code view」として全文を表示する。diff はなし
- タブ（または、パンくずとジャンプ履歴）で、diff と Code view を行き来できる
- Code view でも定義ジャンプと hover が使える

## インタラクション

| 操作                      | 結果                                                          |
| ------------------------- | ------------------------------------------------------------- |
| トークンにホバー（300ms） | LSP の `hover` の結果をポップオーバーで表示する（型と JSDoc） |
| `Cmd+Click` / `F12`       | 定義にジャンプする（[04](./04-code-navigation.md)）           |
| 行番号の横の `+`          | 行メモを追加する（[08](./08-review-state.md)）                |
| ハンク間の移動            | `Alt+F5` / `Shift+Alt+F5`                                     |
| 「VS Code で開く」        | `code --goto <path>:<line>`（Workspace のパス）               |

## 受け入れ条件

- 1,000 行規模の diff を 200ms 以内に初期描画する（ハイライトは非同期で後から当たってよい）
- ホバーとクリックで得られる行・列が、LSP の Position（0 始まり、UTF-16）と一致する。サロゲートペアを含む行のテストを用意する
